# Project Overview


The Smart Attendance Management System is an Android-based application designed to digitize and automate the traditional attendance process.
It moves away from paper-based registers to a more accurate and transparent digital log. 
The app offers two primary methods of attendance: a traditional Manual Toggle for administrators and a modern QR-based Automatic Punch-In system that records the exact time of arrival.


# Tech Stack (The Technologies Used)


1. Language: Java (Backend Logic) and XML (Frontend UI Design).


2. Local Database: SQLite — Provides high-speed, secure, and structured data storage without requiring an internet connection (Offline-first).


3. Camera Integration: CameraX API — Google’s latest library for a stable and high-performance live camera preview.


4. Machine Learning (AI): Google ML Kit (Barcode Scanning) — Used to instantly detect and process QR codes with high accuracy.


5. UI/UX Framework: Material Design 3 — Implements modern components like MaterialCardView, TextInputLayout (OutlinedBox), and FloatingActionButton.


# Key Features


1. Smart Dashboard: A centralized home screen for easy navigation to all app modules.


2. Student Registration: A module to add students/employees with their Full Name and a unique Roll Number/ID.


3. QR-Based Punch-In: Users can scan their unique QR code to mark themselves "Present." The system automatically logs the Exact Time (Punch-In) and Date.


4. Manual Attendance: Allows administrators to manually mark attendance from a list-view (useful for users who forgot their QR codes).


5. Attendance History: A detailed report section showing Student Name, Date, Punch Time, and Status.


6. SQL Inner Joins: The history is generated by joining the Students and Attendance tables to ensure data accuracy.


7. Responsive UI: The layout is optimized to look consistent across different screen sizes and resolutions.


# System Workflow


1. Registration: The Administrator registers a student using the "Add Student" screen.

  
2. Attendance Selection:


. Automatic: The user opens the "Scan QR" screen and presents their QR code (containing their Roll Number).


. Manual: The Admin opens "Manual Attendance" and toggles the status of students in a list.

  
3. Data Processing: The app fetches the current system date and time, then updates the SQLite database.


4. Reporting: The Admin visits "View History" to see a chronological record of all entries.


#  How to Run the Project


# Prerequisites:


1. Android Studio (Ladybug or later recommended).


2. An Android device (Physical phone recommended for testing the Camera/QR features).


# Steps to Execute:

1. Import Project: Open Android Studio and select File > Open, then navigate to the project folder.

  
2. Gradle Sync: Wait for the project to sync the dependencies (ML Kit, CameraX, Material Components).


3. Run: Click the Run button (Green Play icon) to install the app on your device.

  
4. Register a Student: Go to "Add Student," enter a name (e.g., John Doe) and a Roll Number (e.g., 101).

  
5. Test Scanning:


6. Use any online QR generator to create a QR code for the text 101.


7. In the app, click "Scan QR" and point the camera at the generated QR code.


8. You will see a "Punch-In Success" message.

  
9. View Records: Go to the "View History" screen to verify that John Doe is marked present with the exact time.
